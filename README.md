Bitacora Espacial

Portal de noticias del espacio hecho con React y Vite con un sistema de estilos propio

Como correrlo

copiar el archivo .env.example y llamarlo .env
poner la url de la api asi VITE_API_URL=https://api.spaceflightnewsapi.net/v4
npm install
npm run dev
abrir http://localhost:5173

API

Usa Spaceflight News API que es gratis y no pide clave
https://api.spaceflightnewsapi.net/v4
